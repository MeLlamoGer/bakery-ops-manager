# Security and privacy

This repository is a privacy-safe engineering case study, not the production client repository.

## What is intentionally absent

The public repository must not contain:

- real customer names, phone numbers or addresses;
- client-specific commercial pricing;
- private client branding/assets;
- production URLs or credentials;
- Supabase service-role keys or other privileged secrets.

All example records are synthetic.

## Reporting

If you notice information that appears to belong to the real client or any credential-like value, please report it privately to the repository owner rather than opening a public issue containing the value.

See [docs/security.md](docs/security.md) for the anonymization and access-control notes.
